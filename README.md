# Basic Computer Learning

A complete, beginner-friendly computer education website by **Reduan Computer** (Reduan Hossain).

Learn computers step by step — no experience needed. Every lesson is written in simple English, with a Bangla word in brackets only where it helps a Bangladeshi beginner.

**Live website:** https://reduanworksite.github.io/basic-computer-learning/
> Not yet live — this link will work once the project is published to GitHub Pages.

## What you will learn

- **Computer Fundamentals** — what a computer is, types of computers, input/output, data vs information, files and folders, operating systems
- **Hardware & Software** — CPU, RAM, storage, keyboard, mouse, monitor, printer, system vs application software
- **Microsoft Word** — interface, typing and formatting, saving and opening, tables, 5 step-by-step lessons
- **Microsoft Excel** — cells, rows and columns, SUM / AVERAGE / COUNT formulas, charts, 5 lessons, plus a working mini spreadsheet
- **Microsoft PowerPoint** — slides, layouts, design, transitions, presenting, 5 lessons
- **Internet & Email** — browsers, searching, safe browsing, creating and sending email, strong passwords
- **Interactive Quiz** — 16 questions covering every topic, with instant feedback and a saved best score
- **Practice Section** — keyboard practice, mouse click-accuracy game, and a Word formatting playground

## How to run locally

No build step and no installation needed. Just open the site in a browser:

**Option 1 — open the file directly**

Open `index.html` in Google Chrome or any modern browser.

**Option 2 — run a small local server (recommended)**

```bash
cd basic-computer-learning
python3 -m http.server 8000
```

Then visit http://localhost:8000 in your browser.

## Tech used

- Pure HTML, CSS and JavaScript — no framework, no build step, no external JS libraries
- Google Fonts (Inter + Sora) with a system-font fallback, so the site still looks good offline
- Responsive, mobile-first design — works on phone and computer
- Interactive features are real JavaScript: the quiz, the spreadsheet, the keyboard and mouse games, and the formatting playground all actually work
