Lesson 1 • Computer Fundamentals

What is a computer?

A computer is an electronic machine that takes input, processes it, stores it, and gives output. That is the whole idea — everything else is detail.

The 4 jobs of a computer

How a computer works

1. InputKeyboard, mouse — you give information
→
2. ProcessCPU thinks and calculates
→
3. StoreHard disk / SSD keeps files
→
4. OutputScreen, printer — you see the result

Example: You type a letter on the keyboard (input). The computer processes your typing. It stores the letter as a file. You see the letter on the screen and print it (output).

Types of computers

TypeWhat it isGood for

Input and output

Input devices send information into the computer: keyboard (কীবোর্ড), mouse (মাউস), scanner, microphone, webcam.

Output devices bring information out of the computer: monitor (মনিটর), printer, speaker, headphones.

Easy way to remember: Input = in. Output = out. A keyboard is input because your typing goes in. A screen is output because the picture comes out to you.

Data vs information

Data is raw facts — numbers or words with no meaning yet. Example: 85, 90, 70.

Information is data that has been processed and made useful. Example: “Your average mark is 81.”

Computers turn data into information. That is why we use them for accounts, results, lists and letters.

Files and folders

A file is one saved item — a letter, a photo, a song. A folder is a container that holds files, like a drawer holds papers.

  • File name: my-letter.docx — the part after the dot is the file type: .docx is a Word file, .xlsx is Excel, .jpg is a photo.
  • Folder: keep related files together — e.g. a folder called School with your homework files inside.
  • Save often: press Ctrl + S while you work, so you do not lose your work.

Operating system basics

The operating system (OS) is the main software that runs the computer. It starts the computer, shows the desktop, and lets you open programs.

  • Windows — the most common OS on desktops and laptops.
  • macOS — the OS on Apple Mac computers.
  • Android / iOS — the OS on most phones and tablets.

When you turn a computer on, you see the desktop — the main screen with icons. Click an icon to open a program. Use the Start menu (Windows) to find programs, and the taskbar at the bottom to see what is open.

Try it: Turn a computer on, look at the desktop, and open one program — for example, Word or a browser. Then close it again. That is your first computer skill.
