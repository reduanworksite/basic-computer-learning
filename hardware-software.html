Lesson 2 • Hardware & Software

Hardware & Software

Hardware is the parts you can touch. Software is the programs you cannot touch — the instructions that tell the hardware what to do.

Inside the computer — the main parts

Inside a desktop computer (labelled diagram)

CPUCentral Processing Unit — the brain
RAMShort-term memory — work in progress
StorageHard disk / SSD — files kept forever
MotherboardThe main board that connects everything

CPU → thinks & calculates  •  RAM → remembers while you work  •  Storage → keeps files after switch-off

PartWhat it doesSimple idea
CPUProcesses instructions and calculationsThe brain of the computer
RAM (memory)Holds what you are working on right nowA desk — bigger desk, more work at once. Cleared when the computer turns off.
Storage — Hard disk (HDD) / SSDKeeps your files permanentlyA cupboard — files stay there even after switch-off. SSD is faster than HDD.
MotherboardConnects all the parts togetherThe roads between the parts
Power supplyGives electricity to the partsThe plug that powers everything
RAM vs storage — do not mix them up: RAM is temporary (your open work). Storage is permanent (your saved files). If the power goes off, RAM forgets — storage does not. That is why you must save your work.

Outside the computer — devices you use

Input and output devices (labelled diagram)

⌨ KeyboardInput — type letters & numbers
🖱 MouseInput — point & click
🖥 MonitorOutput — shows pictures & text
🖨 PrinterOutput — prints on paper
  • Keyboard (কীবোর্ড): type letters, numbers and symbols. Enter starts a new line, Space makes a gap, Backspace deletes the letter before.
  • Mouse (মাউস): move the pointer, click to select, double-click to open, right-click for a menu, drag to move things.
  • Monitor (মনিটর): the screen — shows what the computer is doing.
  • Printer: puts your document on paper.
  • Speaker / headphone: output for sound. Microphone / webcam: input for voice and video.

Software — two types

TypeWhat it doesExamples
System softwareRuns the computer itselfWindows, macOS, Linux, Android
Application softwareHelps you do a taskWord, Excel, PowerPoint, Chrome, photo editors, games

You need system software first — without an operating system, the computer cannot run any application. Then you install the applications you need for your work.

Quick check: Is Microsoft Word hardware or software? — Software. You cannot touch Word; it is a program. Is a printer hardware or software? — Hardware. You can touch it.
