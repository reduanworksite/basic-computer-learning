Lesson 3 • Microsoft Word

Microsoft Word Lessons

Word is for writing — letters, CVs, assignments and reports. Learn the interface, type and format text, save your work, and make tables.

The Word interface

When you open Word, you see a blank page. The main parts are:

  • Ribbon: the toolbar at the top with tabs — Home, Insert, Layout, Review. The Home tab has the tools you use most.
  • Document area: the white page where you type.
  • Cursor: the blinking line that shows where your typing will appear. Click anywhere to move it.
  • Status bar: the thin bar at the bottom — it shows the page number and word count.

5 step-by-step lessons

Lesson 1 — Open Word and type your first document

  1. Open Word from the Start menu or desktop icon.
  2. Click Blank document.
  3. Type your name and one sentence about yourself.
  4. Press Enter for a new paragraph.
  5. That is it — you have made your first Word document.

Lesson 2 — Format text: bold, italic, size and colour

  1. Select text: click and drag over the words you want to change.
  2. On the Home tab, click B for bold, I for italic, U for underline.
  3. Change the font size with the size box (try 14 or 16).
  4. Change the colour with the font colour button.
  5. Try it live in the formatting playground — no Word needed.

Shortcuts to remember: Ctrl+B bold • Ctrl+I italic • Ctrl+U underline

Lesson 3 — Save and open your document

  1. Press Ctrl + S — the Save window appears the first time.
  2. Type a clear file name, e.g. my-first-letter.
  3. Choose where to save it — Documents is a good place — and click Save.
  4. After that, Ctrl + S saves your changes in one second.
  5. To open it later: open Word, click Open, find the file, and double-click it.
Save often! If the computer turns off before you save, your unsaved work is lost. Make Ctrl + S a habit.

Lesson 4 — Copy, cut, paste and undo

  1. Select the text you want to move or copy.
  2. Ctrl + C copies it. Ctrl + X cuts it (removes it from here).
  3. Click where you want it to go, then Ctrl + V pastes it.
  4. Made a mistake? Ctrl + Z undoes the last action.
  5. Try: copy a sentence, paste it twice, then undo once.

Lesson 5 — Make a table

  1. Click the Insert tab, then Table.
  2. Choose 3 columns and 3 rows for a simple table.
  3. Click inside a cell and type — use Tab to move to the next cell.
  4. Example table: Name | Age | City — fill in three rows of your own.
  5. Save your document with Ctrl + S.
